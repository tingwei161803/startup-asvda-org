# 創業綻放・創業大聯盟競賽 — 入選企業與得獎名單

> 把國發會「創業綻放計畫－創業大聯盟競賽」的 **100 強入選企業、30 強決賽、總統獎與院長獎得主**，整理成一頁可篩選、可搜尋、中英雙語的互動式名錄。

近 3,000 組參賽隊伍、80 位評審、層層篩選，最終選出 100 強、30 強決賽，以及問鼎千萬與百萬級榮譽的 9 組得主。本站把官方公布的三份名單交叉比對、合併成一份完整資料，並為每家入選**企業**補上產業與一句話簡介（可查證者附來源連結），用一頁式長頁呈現整場賽事的故事與全名單。

## ✨ 功能特色

- 🏆 **得獎台** — 總統獎（3 組・各 1,000 萬）與院長獎（6 組・各 600 萬）分組呈現，含組別與城市
- 📉 **賽事漏斗** — 3,000 → 100 → 30 → 9 的篩選歷程一目了然
- 🗂️ **100 強互動名錄** — 五軸獨立篩選（**組別 × 產業 × 企業／團隊 × 賽區 × 晉級階段**）+ 即時搜尋 + 詳情視窗
- ✅ **誠實標記，不造假** — 已查證的公司才顯示產業、簡介與來源連結；**查無公開資料者，卡片只顯示「查無公開資料」**，依名稱所做的推估收進詳情視窗、並在前面加上醒目警示橫幅，絕不把推測當事實呈現；團隊組依規定去識別化
- 📊 **入選結構圖** — 報名類別（前瞻 31／消費 38／綠色 31）與企業／團隊（81／19）甜甜圈圖
- 🌏 **雙語切換** — 中文 / English 一鍵全頁切換（含公司名、產業、簡介、介面）
- 🌗 **深色 / 淺色模式** — 預設深色「頒獎典禮」風，可切換為淺色編輯風，記憶於 localStorage
- 🔗 **深連結** — 每家公司都有專屬 `#<參賽編號>`，可直接分享
- 📱 **響應式設計** — 手機、平板、桌機皆適配
- ⚡ **純靜態** — 無後端、無建置流程、載入快、可離線瀏覽

## 📂 內容結構 / 資料來源

本站內容整理自 **國家發展委員會「創業綻放計畫－創業大聯盟競賽」官方公布名單**（複賽 100 強、決賽 30 強、總統獎及院長獎名單），各公司產業與簡介另整理自公開網路資料。

```
startup-asvda-org/
├── index.html              # 入口頁（單頁式）
├── assets/
│   ├── styles.css          # 設計 tokens（深/淺）+ 全部元件樣式
│   ├── app.js              # 區段渲染、四軸篩選、搜尋、詳情視窗、i18n
│   └── og-image.png        # 社群分享預覽圖
├── data/
│   ├── build_raw.py        # 三份官方名單 → raw_companies.json（交叉比對 + 數量驗證）
│   ├── raw_companies.json  # 100 家公司的事實骨架（編號/名稱/組別/賽區/階段/獎項）
│   ├── enrich-01..09.json  # 9 個研究批次的產業/簡介/來源（web 整理）
│   ├── _assemble.py        # raw + enrich → data.js
│   └── data.js             # 產生檔；window.SITE_* 全域資料
├── sources/                # 官方名單原始 PDF（資料來源存證）
├── .nojekyll               # 讓 GitHub Pages 跳過 Jekyll
└── README.md
```

### 資料管線（可重現）

資料層完全可由原始檔重建，全程使用 `uv`：

```bash
uv run python data/build_raw.py     # 由三份名單建立事實骨架，並驗證數量（81 企業 / 19 團隊；前瞻31/消費38/綠色31）
uv run python data/_assemble.py      # 合併研究批次與骨架，輸出 data/data.js
```

`build_raw.py` 內含對官方統計的斷言（`assert`），任何數量對不上會立即報錯——事實以**官方名單**為準，網路整理只負責補產業與簡介。

> ⚠️ **非官方**：本網站為個人整理之非官方資源，名單事實整理自上述官方來源，公司產業／簡介為公開網路資料整理（標示「已查證」者附來源連結，「推估」者僅依名稱與組別推測、未必正確）。名單排序依官方規則（公司名稱筆畫／團隊編號），與評審分數無關；團隊組參賽者姓名依官方名單去識別化。如有錯誤或出入，請以官方來源為準。

## 🛠 本機使用

```bash
# 1. clone 專案
git clone git@github.com:tingwei161803/startup-asvda-org.git
cd startup-asvda-org

# 2a. 最簡單：直接開啟 index.html
open index.html

# 2b. 或啟動本機伺服器（建議，深連結才正常）
uv run python -m http.server 4173
# 然後瀏覽 http://localhost:4173
```

> 本專案為純靜態網站，瀏覽不需安裝任何依賴。若要重建資料層或跑測試，依使用者偏好一律使用 `uv`。
